## Project Overview

This project focuses on analyzing online education data to understand student engagement, academic performance, and dropout patterns.

The dashboard provides meaningful insights into student learning behavior using data analysis and visualization. It helps identify performance trends, engagement levels, and potential dropout risks to support better decision-making.

---

## Objectives

- Analyze student academic performance.
- Understand student engagement and learning activity.
- Identify dropout patterns and at-risk students.
- Explore the relationship between engagement and performance.
- Present key insights through interactive visualizations.

---

## Dataset

The dataset contains student-related information and learning activity metrics.

| Column | Description |
|---|---|
| Student ID | Unique identifier for each student |
| Total Clicks | Student activity and interaction count |
| Average Score | Average academic score |
| Studied Credits | Credits studied by the student |
| Engagement Level | Student engagement category |
| Performance Level | Academic performance category |
| Dropout Flag | Indicates whether the student dropped out |

---

## Dashboard KPIs

| KPI | Description |
|---|---|
| Total Students | Total student records analyzed |
| Average Score | Overall average student score |
| Pass Rate | Percentage of students who passed |
| Dropout Rate | Percentage of students who dropped out |
| Average Studied Credits | Average credits studied per student |
| Maximum Clicks | Highest recorded student activity |

---

## Key Insights

- Student engagement levels help understand learning activity and performance patterns.
- Academic performance varies across different engagement levels.
- Dropout analysis helps identify students who may require additional support.
- Interactive filters allow analysis across different student categories.
- Data visualization makes student performance trends easier to understand.
